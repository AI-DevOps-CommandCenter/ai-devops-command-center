# n8n Workflows

This directory stores exported n8n workflow files for the AI-Powered Mobile DevOps Command Center.

## Planned Workflows

* **Incident Ingestion:** Receive monitoring alerts through an n8n webhook.
* **AI Investigation:** Analyze incident details and generate possible root causes.
* **Remediation Approval:** Request human approval before performing remediation.
* **Recovery Verification:** Check whether the incident has been resolved.
* **Postmortem Reporting:** Generate incident summaries and reports.

## File Format

Export n8n workflows as JSON files and store them in this directory.

## Security

Never include API keys, passwords, access tokens, or other secrets in exported workflow files.
