    # Sample Application

This directory is reserved for a sample application used to test the AI-Powered Mobile DevOps Command Center.

## Purpose

The sample application will help the team test monitoring alerts, incident investigation, and recovery verification.

## Planned Tests

* Run the application and confirm that it is healthy.
* Simulate an application failure in a controlled test environment.
* Verify that monitoring tools detect the failure.
* Confirm that the incident reaches the n8n workflow.
* Test recovery verification after the application is restored.

## Ownership

Coordinate the implementation and testing of this application with the team member responsible for the sample application.

## Safety

Only simulate failures in the designated test environment. Do not intentionally disrupt production systems.
